Описание

R4ezka — неофициальный Android-клиент для сайта Rezka TV. Приложение предоставляет удобный мобильный интерфейс для просмотра каталога, поиска фильмов и сериалов, управления избранным и историей просмотра, а также воспроизведения контента во встроенном плеере.

  • 🎬 Каталог фильмов и сериалов
  • 🔎 Поиск по каталогу
  • 📺 Просмотр информации о фильмах и сериалах
  • ▶️ Встроенный видеоплеер
  • ⭐ Избранное
  • 🕘 История просмотра
  • 📱 Интерфейс, адаптированный для Android
  • 🌙 Современный интерфейс на Jetpack Compose
